A small update: `drop open` no longer steals focus.

## What's new

- **`drop open` stays in the background:** the Agent Drop window comes to the front on the drop, but the app you're typing in (usually your terminal) keeps focus. This works whether the app is already running or `drop open` launches it.
- **`drop open --foreground` (`-f`):** the old behavior, for when you do want to switch to Agent Drop.
- Clicking a notification or a drop in the menu bar still brings the app forward.

## Install

Download `AgentDrop-0.2.1.zip`. It's universal: Apple silicon and Intel, macOS 14 or later. Then:

```bash
cp -R AgentDrop.app /Applications/
rm -f /usr/local/bin/drop; cp drop /usr/local/bin/drop   # or any directory on your PATH
xattr -dr com.apple.quarantine /Applications/AgentDrop.app /usr/local/bin/drop
open /Applications/AgentDrop.app
```

These builds are ad-hoc signed, not notarized. Clearing the quarantine flag once, or right-clicking the app in Finder → Open, lets macOS run them. To check the download: `shasum -a 256 -c AgentDrop-0.2.1.zip.sha256`.

Updating: quit Agent Drop first, and remove the old `drop` before copying the new one (as above). macOS kills a signed binary that was overwritten in place.
