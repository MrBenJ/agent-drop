A small fix: Quick Look previews hold still.

## What's fixed

- **Previews no longer flash:** an image or other Quick Look preview used to reload over and over whenever anything changed in the drop folder, most noticeably while a file was uploading over your tailnet. Now a preview only refreshes when the file you're looking at actually changes.

## Install

Download `AgentDrop-0.2.2.zip`. It's universal: Apple silicon and Intel, macOS 14 or later. Then:

```bash
cp -R AgentDrop.app /Applications/
rm -f /usr/local/bin/drop; cp drop /usr/local/bin/drop   # or any directory on your PATH
xattr -dr com.apple.quarantine /Applications/AgentDrop.app /usr/local/bin/drop
open /Applications/AgentDrop.app
```

These builds are ad-hoc signed, not notarized. Clearing the quarantine flag once, or right-clicking the app in Finder → Open, lets macOS run them. To check the download: `shasum -a 256 -c AgentDrop-0.2.2.zip.sha256`.

Updating: quit Agent Drop first, and remove the old `drop` before copying the new one (as above). macOS kills a signed binary that was overwritten in place.
