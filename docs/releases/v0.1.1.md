A small update to the Agent Drop app: work on several drops at once.

## What's new

- **Right-click menu in the list:** Reveal in Finder, Open in VS Code, and Archive / Unarchive. Right-click a selected row to act on the whole selection, or any other row to act on just that one.
- **Select several drops:** Cmd-click, Shift-click, Shift-arrow keys and Cmd-A work like they do in Finder and Mail. With more than one selected, the detail pane shows how many and offers the same actions.
- Selecting several drops doesn't mark them read; only a single selection does.

## Fixed

- Long sidebar names in the window title now end in an ellipsis instead of running across the list column.

## Install

Download `AgentDrop-0.1.1.zip`. It's universal: Apple silicon and Intel, macOS 14 or later. Then:

```bash
cp -R AgentDrop.app /Applications/
cp drop /usr/local/bin/drop          # or any directory on your PATH
xattr -dr com.apple.quarantine /Applications/AgentDrop.app /usr/local/bin/drop
open /Applications/AgentDrop.app
```

These builds are ad-hoc signed, not notarized. Clearing the quarantine flag once, or right-clicking the app in Finder → Open, lets macOS run them. To check the download: `shasum -a 256 -c AgentDrop-0.1.1.zip.sha256`.
