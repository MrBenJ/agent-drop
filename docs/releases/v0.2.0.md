Agent Drop 0.2.0 lets an agent on another Mac drop work into your Agent Drop over Tailscale.

## What's new

- **Drops over your tailnet:** Settings → General → Tailnet has a new **Receive drops from my tailnet** switch (off by default). Turn it on and the app listens on your Mac's Tailscale address only, port 47400. **Copy setup command** gives you the line to run on the other Mac, **Copy key** just the key; **Regenerate key** cuts off old senders.
- **`drop remote`:** `drop remote add|list|remove|test` manages the Macs you can send to. Keys are never shown, and `--key -` reads one from stdin so it stays out of shell history.
- **`drop add --to <remote>`:** send a file, a folder or stdin to another Mac, with no local setup on the sender. `--to env` uses `AGENT_DROP_REMOTE_URL` and `AGENT_DROP_REMOTE_KEY`.
- **Safe by design:** the tailnet side accepts only adding a drop and a connection test, never reading. Drops are limited to 200 MB, two at a time, and refused if less than 1 GB of disk would be left. Folders with links or odd paths are rejected whole.
- **Skills for OpenClaw and Hermes:** `Scripts/install-agent-skills.sh --openclaw --hermes` installs an `agent-drop-send` skill. See `skills/README.md`.
- `drop agent-instructions` now mentions `--to`.

Note: the app is ad-hoc signed, so with the macOS firewall on, it may ask to accept incoming connections again after each update.

## Fixed

- The local server's access-token check is now constant-time.

## Install

Download `AgentDrop-0.2.0.zip`. It's universal: Apple silicon and Intel, macOS 14 or later. Then:

```bash
cp -R AgentDrop.app /Applications/
cp drop /usr/local/bin/drop          # or any directory on your PATH
xattr -dr com.apple.quarantine /Applications/AgentDrop.app /usr/local/bin/drop
open /Applications/AgentDrop.app
```

These builds are ad-hoc signed, not notarized. Clearing the quarantine flag once, or right-clicking the app in Finder → Open, lets macOS run them. To check the download: `shasum -a 256 -c AgentDrop-0.2.0.zip.sha256`.
