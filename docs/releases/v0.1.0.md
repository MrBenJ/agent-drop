The first release of Agent Drop: a macOS app and the `drop` CLI. Coding agents (Claude Code, Codex, pi, …) use them to hand each other files with context, and you browse what they left.

## What's in it

**`drop` CLI**
- Agents drop files and folders with a title, a description, a project, tags and who made them.
- They can mark a drop as a handoff for another agent, and find, read, claim and finish handoffs.
- Every command has `--json`. It works without the app.

**`drop watch`**
- Streams changes from the app's local server: new handoffs in the Inbox, or every change to one drop.
- The server is loopback-only and protected by a token.

**AgentDrop.app**
- **Menu bar:** an unread count, recent drops, and the Inbox.
- **Main window:** All Drops, Inbox, Handoffs, Unregistered and Archived views. Projects, tags and `from` values show as trees when they contain `/`.
- **Previews:** rendered Markdown, plus text, Quick Look and folder previews. Links are never followed.
- **Actions:** handoff buttons, editing, and notifications.
- **First run:** a setup screen, with an optional launch at login.

**`drop open <id>`** shows a drop in the app.

## Install

Download `AgentDrop-0.1.0.zip`. It's universal: Apple silicon and Intel, macOS 14 or later. Then:

```bash
cp -R AgentDrop.app /Applications/
cp drop /usr/local/bin/drop          # or any directory on your PATH
xattr -dr com.apple.quarantine /Applications/AgentDrop.app /usr/local/bin/drop
open /Applications/AgentDrop.app
```

These builds are ad-hoc signed, not notarized. Clearing the quarantine flag once, or right-clicking the app in Finder → Open, lets macOS run them. To check the download: `shasum -a 256 -c AgentDrop-0.1.0.zip.sha256`.

Teach your agents with `drop agent-instructions >> CLAUDE.md` (or `AGENTS.md`).

## Known limits

- Not notarized, and no Homebrew formula yet.
- Rendered Markdown may load images from `https:` URLs.
- If you delete the whole drop folder while the app runs, it keeps showing the old data until the folder setting changes or you restart the app.

See the [design spec](https://github.com/MrBenJ/agent-drop/blob/main/docs/superpowers/specs/2026-10-11-agent-drop-design.md) for how it all works.
